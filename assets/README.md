# assets/

| Fil / mapp | Innehåll |
|---|---|
| `ginatricot-logo.svg` | **Lägg varumärkets logotyp här.** Den läses in av startskärmen och den belysta skylten ovanför entrén. Filen ingår inte i repot – om den saknas visas `logo-placeholder.svg`. |
| `logo-placeholder.svg` | Neutral platshållare som visas tills den riktiga logotypen finns. |
| `products/` | Produktbilder (`images[]`) och transparenta PNG:er för AR-provning (`tryOnImage`). Genererade platshållare – byt mot riktiga bilder. |
| `campaign/` | Kampanjbilder som roterar på de digitala skärmarna (stående, ca 9:16). |
| `photos/` | Bilder till de inramade modefotona på väggarna. |
| `models/` | Valfria `.glb`-modeller som ersätter de enkla, inbyggda modellerna (se README i projektroten). |
